# uniWAHL OWS SmartLink

SmartLink ist das Single-Sign-on-Verfahren der uniWAHL OWS-Plattform. Wählerinnen und Wähler, die in Ihrer eigenen Anwendung bereits angemeldet sind, gelangen damit ohne zweite Anmeldung in die Wahlkabine einer bestimmten Wahl.

Diese Dokumentation richtet sich an die Entwicklerinnen und Entwickler der Anwendung, die den SmartLink erzeugt.

| Plattform | Dokumentation | Referenzimplementierungen |
|---|---|---|
| Zweite Generation (GEN2) | [SmartLink in GEN2](./gen2/einleitung.md) | [Java, Go, Rust, PHP](./gen2/referenzimplementierungen.mdx) |

Sie wechseln von der ersten Generation? Dann beginnen Sie mit [Umstieg von GEN1 auf GEN2](./gen2/umstieg-gen1.md).
