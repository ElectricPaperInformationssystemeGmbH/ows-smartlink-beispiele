# Referenzimplementierungen

Für die Erzeugung von auth-token und SmartLink stehen Referenzimplementierungen in vier Sprachen bereit. Jede führt zuerst einen Selbsttest mit festen Beispielwerten aus und gibt `Selbsttest bestanden` und einen Beispiel-Link aus; alle vier erzeugen dabei zeichengleich denselben Link. Tragen Sie anschließend die Angaben aus Ihrer SmartLink-Zugangsdaten-Datei in die leeren Felder ein.

Der Code unten ist derselbe wie im [Repository](https://github.com/ElectricPaperInformationssystemeGmbH/ows-smartlink-beispiele/tree/main/gen2); eine GitHub-Action führt die Selbsttests bei jeder Änderung aus.
